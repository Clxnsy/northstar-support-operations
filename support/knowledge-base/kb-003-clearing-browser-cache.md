# KB-003: Clearing Browser Cache & Resolving Web Portal Errors

## Overview
Web browsers store local copies of scripts, stylesheets, and security tokens to speed up page loading. Corrupted or stale cache files can cause blank white screens, button unresponsiveness, or payment gateway token errors (ERR-PAY-902).

---

## Step-by-Step Cache Clearing Instructions

### Google Chrome
1. Click the **Three Dots** menu icon in the top-right corner.
2. Select **Delete Browsing Data** (or press `Ctrl + Shift + Delete` on Windows / `Cmd + Shift + Delete` on Mac).
3. Set Time Range to **All Time**.
4. Check the boxes for **Cookies and other site data** and **Cached images and files**.
5. Click **Delete Data**.
6. Restart your browser and log back into Northstar.

### Mozilla Firefox
1. Click the **Hamburger Menu** icon and select **Settings**.
2. Go to **Privacy & Security**.
3. Scroll down to **Cookies and Site Data** and click **Clear Data...**.
4. Ensure both **Cookies** and **Cached Web Content** are checked and click **Clear**.

### Apple Safari (macOS)
1. Open Safari and click **Safari** in the top menu bar -> **Settings**.
2. Go to the **Advanced** tab and check **Show features for web developers**.
3. In the top menu bar, click **Develop** -> **Empty Caches**.
