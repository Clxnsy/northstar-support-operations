# KB-006: Checking System Status & Data Pipeline Operations

## Overview
Northstar maintains a transparent 24/7 system availability and data processing status portal.

---

## Checking Platform Uptime
* Visit our official Status Page at `https://status.northstar.com`.
* Review real-time operational status indicators for:
  * **Core Web Platform & API Gateway**
  * **Authentication & SSO Cluster**
  * **Nightly Billing & Invoicing Engine**
  * **Telemetry Data Pipeline & Analytics**

---

## Understanding Maintenance Windows
Scheduled maintenance updates occur during low-traffic hours:
* **Weekly Maintenance Window:** Sundays from **01:00 AM to 03:00 AM MT**.
* During scheduled maintenance, API responses may experience brief latency (< 30 seconds). Major updates are announced 7 days in advance via banner notifications.
