# KB-007: Reporting Software Bugs & Workaround Procedures

## Overview
If you encounter an application error, UI glitch, or unexpected software behavior, follow this guide to submit a comprehensive bug report that enables rapid engineering resolution.

---

## How to Submit a High-Quality Bug Report
When submitting a bug via the Northstar Customer Support Portal, include the following mandatory diagnostic details:

1. **Exact Page URL:** The web address where the error occurred (e.g., `https://app.northstar.com/analytics/reports`).
2. **Step-by-Step Reproduction:**
   * Step 1: Clicked 'Analytics'.
   * Step 2: Filtered date range to 'Q2 2026'.
   * Step 3: Clicked 'Export as CSV'.
3. **Expected vs Actual Behavior:** Describe what should have happened versus what actually occurred.
4. **Error Message & Screenshots:** Attach screenshots of any red error callout banners or browser console log errors.
5. **Browser & OS Specs:** Indicate your browser name/version (e.g., Chrome 124 on macOS Sonoma).
