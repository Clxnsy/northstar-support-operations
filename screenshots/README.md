# Screenshots & Visual Assets Guide
**Project:** Northstar Support Operations System  

---

## Recommended Portfolio Screenshots
To further enhance your GitHub repository's recruiter appeal, capture and add the following 6 screenshots to this folder:

1. `jsm-customer-portal.png`: The Jira Service Management Customer Portal showing the 6 structured Request Types.
2. `jsm-queue-dashboard.png`: The JSM Agent Interface displaying the 8 configured support queues (P1 Emergency, Triage, Auth, Billing, etc.).
3. `jsm-ticket-workflow.png`: An active ticket view showing internal notes (yellow callout box), customer communications, and SLA countdown timers.
4. `sql-query-execution.png`: A database GUI tool (DBeaver, DataGrip, or pgAdmin) executing `queries.sql` showing query results.
5. `uat-test-execution.png`: Spreadsheet or CSV view of `uat-test-cases.csv` displaying green PASS / red FAIL status badges.
6. `kb-help-center.png`: Customer-facing Help Center page displaying Knowledge Base articles.

---

## File Naming Convention
Save image files in PNG or JPG format using the exact filenames listed above. Reference them in `README.md` using standard markdown image tags:
`![JSM Portal](screenshots/jsm-customer-portal.png)`
